# StudyFlow

StudyFlow is an installable student task tracker and FON Mathematics Department registration monitor.

## Features

- Local student tasks with subjects, due dates, priorities, and filters
- Installable Progressive Web App with offline support
- Monitors public Mathematics Department activity posts containing `prijav` / `пријав`
- Subject filters and expired-deadline indicators
- Automated update checks every 30 minutes through GitHub Actions

## Data source

Public activity posts from <https://math.fon.bg.ac.rs/aktivnosti>.

Automatically extracted deadlines should always be verified against the linked original announcement.
